# Fonts

All three are licensed under the SIL Open Font License 1.1.

- Inter, by Rasmus Andersson
- Space Grotesk, by Florian Karsten
- JetBrains Mono, by JetBrains

Files come from the `@fontsource-variable/*` packages.
